# TicketGo — Postman API Tests

This directory contains API testing exercises created in Postman.

## Scope

- GET requests and query parameters
- POST requests with JSON bodies
- Positive and negative input examples
- Response structure validation
- Data type assertions
- Required field validation

## Execution Notes

These exercises use Postman Echo, which returns submitted data.

They do not test a live TicketGo booking API.
