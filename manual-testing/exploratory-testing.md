## Charter 01 — Login

**Mission:** Explore potential issues with user login and authentication.

**Scope:** Login page and access to user accounts.

**Risks:**
- Unauthorized access to accounts
- Incorrect authentication behavior
- Exposure of another user's information

**Test Ideas:**
1. Attempt login using valid test credentials.
2. Attempt login with an incorrect password.
3. Verify that one test account cannot access another test account's private information.
4. Observe login behavior after refreshing the page.

**Duration:** 30 minutes (planned)

**Execution Status:** Not Run

## Charter 02 — Booking

**Mission:** Explore potential issues with ticket selection, passenger information, and price calculation.

**Scope:** Booking page, passenger details, and total price.

**Risks:**
- Incorrect price calculation
- Incorrect passenger count
- Loss of entered information

**Test Ideas:**
1. Increase the ticket count and observe the total price.
2. Decrease the ticket count and check whether the price updates.
3. Enter passenger details, refresh the page, and observe whether the data is preserved.
4. Attempt to select more than five tickets.

**Duration:** 30 minutes (planned)

**Execution Status:** Not Run
